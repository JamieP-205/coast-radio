# Coast Internet Radio

A rebuild of the website for Coast Internet Radio, a small internet radio station in Newry run by Jim Parr, playing country, Irish country and classic hits 24 hours a day.

## Status

In progress. The current live site stays at coastinternetradio.com until this version is finished and tested.

## How it's built

Plain HTML, CSS and JavaScript, with no framework. The station's audio stream and track information come from two Cloudflare Workers that serve them over HTTPS.
